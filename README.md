🎓🎓🎓 STUDENT MANAGEMENT SYSTEM 🎓🎓🎓

📘 Project Overview

The Student Management System is a web-based application developed using Java, JDBC, Servlets, JSP, and MySQL.
This project is designed to manage student records and user accounts efficiently while following MVC architecture and core Java backend development best practices.

The system provides secure authentication, session management, and complete CRUD operations for student data, making it a practical real-world application for understanding enterprise Java web development.

⸻

📋 Features

👤 User Module
	•	User Registration
	•	User Login with session management
	•	View & Update User Profile
	•	Secure Logout functionality

🎓 Student Module
	•	Add new student records
	•	View all students in tabular format
	•	Search student by ID or name
	•	Update existing student details
	•	Delete student records

⸻

🏗 Architecture

The project follows MVC (Model–View–Controller) architecture:
	•	Model: JDBC + MySQL for data persistence
	•	View: JSP pages with HTML, CSS, and Bootstrap
	•	Controller: Servlets handling requests and responses

This structure improves maintainability, scalability, and separation of concerns.

⸻
